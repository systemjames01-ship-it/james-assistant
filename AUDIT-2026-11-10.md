# Jâmes repository audit — 2026-11-10

This audit branch is isolated from `main`. No Worker deployment, D1 query, secret change, or production edit was performed.

## Verified in the current main branch

- `worker.js` uses only `gemini-3.8-flash`; there is no configured fallback model.
- The request parser accepts the legacy `image` field, but no `attachments` parser is present.
- D1 history operations call `ensureConversationTable()`, which creates an assumed schema and index at runtime.
- A D1 failure blocks the message response because history load/save are inside the main request's fatal try/catch.
- The assistant tool declaration contains only `get_current_time`; it is not a general task-execution or web-research system.
- The frontend sends `image` and expects `{ reply }`.
- The repository main branch did not contain `package.json`, `schema.sql`, or `DIFF_REPORT.md` at audit time.

## Verified Google model documentation

The official model catalog lists `gemini-3.8-flash` and `gemini-3.5-flash-lite`. The official pricing page lists free-tier text/image input and output for both standard modes. Free-tier usage is subject to quotas and Google data-use terms; free tier is not an unlimited guarantee.
