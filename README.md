# Jâmes — Sistema Autônomo v3
Jâmes é a IA pessoal de Jamerson Ramos: PWA instalável + Worker + camada Android nativa.
A interface tem três áreas: Núcleo holográfico, Chat privado e Painel de controle.
Microfone e câmera são solicitados pelo sistema operacional; ações profundas dependem do cliente nativo e das permissões concedidas.
